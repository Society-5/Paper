# Paper

LaTeX sources for the Society-5 project write-up: autonomous exploration with a WowWee Robosapien X using QR-code markers, collision detection, and a mixed-reality control interface.

The repository's `.gitignore` only allows `*.tex`, `*.png` and `*.md` files. The paper itself has not been committed yet.

---

Part of **[Society-5](https://github.com/Society-5)**: a WowWee Robosapien X that explores a floor on its own, using a phone camera and QR codes as markers, with a mixed-reality (VR) interface for remote control. See [Introduction](https://github.com/Society-5/Introduction) for the project overview.
